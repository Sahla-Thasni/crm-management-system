# CRM Management System

A full-stack Customer Relationship Management (CRM) application developed as a team project to manage leads, companies, deals, tickets, and customer activities.

## Features
- Dashboard and sales reports
- Lead and company management
- Deal and ticket management
- Activity tracking, including calls, emails, meetings, tasks, and notes
- JWT authentication and REST API integration

## Tech Stack

**Frontend:** Next.js, React, TypeScript, Material UI, Redux Toolkit

**Backend:** Python, Django REST Framework

**Database:** PostgreSQL

## Project Structure

- `frontend/` – Next.js frontend application
- `backend/` – Django REST API backend
